# GLASS-DOLAR

Aplicação simples e eficiente para conversão de moedas com foco em taxas de câmbio do dólar americano (USD).

## 📋 Descrição

GLASS-DOLAR é uma aplicação desenvolvida para facilitar a consulta e conversão de valores entre o Real Brasileiro (BRL) e o Dólar Americano (USD), fornecendo taxas de câmbio atualizadas em tempo real.

## 🚀 Funcionalidades

- Conversão rápida entre BRL e USD
- Taxas de câmbio em tempo real
- Interface simples e intuitiva
- Cálculos precisos e confiáveis
